# Свои хуки курса

Таблица всех хуков проекта (критерий О9). Формат: сигнатура, что возвращает,
какие граничные случаи учтены. Параметры варианта 3: `delay` поиска - 500 мс,
префикс ключей - `sc-charlie` (docs/README.md, таблица вариантов).

| Хук | Сигнатура и возврат | Граничные случаи |
|-----|---------------------|------------------|
| H1 `useDebouncedValue` | `(value: T, delay: number) => T` - отложенная копия значения | меняется не раньше `delay` после последнего изменения входа; частые обновления перезапускают таймер; после размонтирования ничего не применяется |
| H1 `useDebouncedCallback` | `(fn: (...args: A) => void, delay: number) => DebouncedCallback<A>` с методами `cancel()` и `flush()` | вызывает всегда последнюю `fn` (обновляется после каждого рендера), таймер перезапускается частыми вызовами, `flush` берёт аргументы последнего вызова, размонтирование отменяет отложенный вызов |
| H3 `useOutsideClick` | `(ref, handler, isActive) => void` - зовёт `handler(event)` по mousedown вне элемента | подписка на document только при `isActive`; новый `handler` не пересоздаёт подписку; слушается mousedown, а не click; цель события проверяется через `instanceof Node` |
| H3 `useKeydown` | `(key, handler, isActive) => void` - `handler(event)` по нажатию `key` | подписка только при `isActive`; смена `key` переслушивает клавишу; смена `handler` не пересоздаёт подписку; после размонтирования обработчики сняты |
| H4 `useUrlState` | `(name, defaultValue, parse) => [value, setter]` - значение в query-параметре | некорректное/отсутствующее значение - default, адрес не перезаписывается; setter копирует актуальные параметры (посторонние сохраняются), `undefined` стирает параметр, `replace: true` не создаёт запись истории |
| H5 `useYandexMap` | `(containerRef, city, offers, activeOfferId) => 'no-key' \| 'loading' \| 'ready' \| 'error'` | скрипт API грузится один раз на приложение (кэш промиса); карта создаётся один раз, при смене города двигается только центр, при смене списка - только маркеры, активное предложение перекрашивает свой маркер классом; при размонтировании - `destroy`; без ключа скрипт не грузится |
| H6 `usePersistentState<T>` | `(key, initialValue, validate) => [value, setValue, remove]` - состояние в localStorage | ленивая инициализация чтением; битый JSON и данные не той формы - `initialValue`; ошибка записи (квота, приватный режим) не роняет приложение; смена `key` не утаскивает чужой черновик; событие `storage` синхронизирует вкладки |
| H8 `useReviewForm` | `(offerId, submitReview?) => { rating, text, status, error, isValid, setRating, setText, submit }` - автомат формы отзыва | переходы editing -> submitting -> success \| error; недопустимые переходы и невалидная отправка игнорируются; во время отправки форма заблокирована; при ошибке данные не теряются; черновик - через H6, после успеха удаляется; отправка по умолчанию - заглушка с задержкой |
| H12 `useMediaQuery` | `(query: string) => boolean` - подходит ли экран под медиазапрос | реализован на `useSyncExternalStore` + `matchMedia` (без события resize); первое значение читается сразу, «мигания» нет; на сервере - false; смена `query` переслушивает |

Каждый хук лежит в `src/hooks/<имя-хука>/<имя-хука>.ts`, тесты - рядом.
Редьюсер формы отзыва вынесен в `review-form-reducer.ts` и тестируется
отдельно как чистая функция; загрузчик API карт - в
`use-yandex-map/load-yandex-maps.ts`.
